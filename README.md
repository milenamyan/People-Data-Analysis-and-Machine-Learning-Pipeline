# 🧠 People Data Analysis and Machine Learning Pipeline

A full data science workflow for analyzing a dataset of 1.2M+ people, including data cleaning, exploratory analysis, clustering, and predictive modeling using **Python**, **Pandas**, and **scikit-learn**.

---

## 🚀 Features

- **Data Cleaning** — Handles missing values, standardizes text, computes age at death
- **Exploratory Data Analysis (EDA)** — Summaries, minimal visuals, and trend insights
- **Clustering** — Groups people by age, era, and other traits using K-Means
- **Predictive Modeling** — Trains Random Forests to predict life or death-related outcomes
- **Summary Report** — Generates key statistics and charts for presentations

---

## 🧩 Tech Stack

- 🐍 Python 3.10+
- 📦 Libraries:
  - pandas
  - numpy
  - matplotlib
  - seaborn
  - scikit-learn
  - reportlab _(optional, for PDF export)_
